## About Argenox

Argenox develops embedded connectivity and security solutions focused on wireless systems, embedded firmware, modern cryptography, and secure device development.

Our projects and tools are designed for engineers building production-ready embedded systems, IoT devices, and secure connected products.

We specialize in:

- Bluetooth Low Energy (BLE)
- Wi-Fi and wireless systems
- Embedded firmware and RTOS integration
- TLS and cryptography
- Secure manufacturing and provisioning
- RF testing and optimization
- Mobile Android and iOS applications
- Embedded security architecture

## Featured Projects

### NoxTLS
Lightweight embedded TLS and cryptography library designed for constrained systems and modern security.

Features:

- TLS 1.3 support
- Embedded-focused architecture
- Cortex-M optimized
- Hardware acceleration ready
- Modern cryptography support
- Designed for production systems

Repository:
https://github.com/argenox/noxtls

---

### NoxTLS-RS
Rust implementation of NoxTLS focused on memory safety and embedded systems.

Features:

- `no_std` support
- Embedded Rust focused
- Modern cryptography
- Secure and lightweight architecture

Repository:
https://github.com/argenox/noxtls-rs

---

### BlueNox Android

Modern Android BLE library designed for reliability and ease of integration.

Repository:
https://github.com/argenox/bluenox-android
